Comment l'installer ?
  1. Touche « Télécharger », puis « Télécharger quand même » si le téléphone prévient.
  2. Ouvre le fichier téléchargé (dans les notifications ou dans Fichiers › Téléchargements).
  3. Si le téléphone le demande, autorise l'installation, reviens, puis touche « Installer ».
  4. Si un avertissement s'affiche : « Plus de détails » › « Installer quand même ».

Ensuite l'appli se met à jour toute seule.
